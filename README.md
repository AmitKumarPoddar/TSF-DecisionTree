# TSF-DecisionTree
Created the decision tree classifier for the classification of flowers from the Iris dataset. So that if we feed any new data to this classifier, it would be able to predict the right class accordingly.
Dataset : https://bit.ly/3kXTdox

## Mexico trade explorer

`trade_viability/` contains a Streamlit app. It searches HS codes by
material name, then fetches Mexico's yearly imports and exports from the
Data México API, with charts and signals for the opportunity-viability
tests. See [trade_viability/README.md](trade_viability/README.md).
